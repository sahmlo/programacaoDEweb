Este repositório reúne os exercícios práticos e projetos desenvolvidos no módulo de **Programação Web** do curso técnico de Desenvolvimento de Sistemas.

O objetivo principal foi dominar a camada de apresentação (**Front-end**) das aplicações, aprendendo a criar interfaces responsivas, semânticas e interativas para usuários finais.

---

## 🛠️ Tecnologias Utilizadas

| Tecnologia | Aplicação no Projeto |
| :--- | :--- |
| 🧱 **HTML5** | Estruturação semântica e esqueleto das aplicações. |
| 🎨 **CSS3** | Estilização, Design Responsivo e construção de layouts com Flexbox e Grid. |
| ⚡ **JavaScript** | Interatividade no lado do cliente (Client-side) e manipulação do DOM. |

---

## 🎯 Objetivo no Curso

No contexto de Desenvolvimento de Sistemas, este módulo serve como fundação para a formação de um desenvolvedor **Full Stack**, permitindo:

1. **Criação de Interfaces:** Construção de telas de cadastro, dashboards administrativos e landing pages.
2. **Experiência do Usuário (UX/UI):** Compreensão de como entregar um software funcional e visualmente agradável.
3. **Integração:** Preparação do terreno para conectar a interface front-end com o Back-end (servidores e banco de dados).
